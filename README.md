### Hi, I'm Samuel 👋

I'm a doctoral researcher in Computational Engineering (Applied Mathematics) at LUT University, Finland. I study inverse problems for waves: recovering what's inside a pipe from how waves travel through it, and quantifying how confident we can be in the result. 

🌐 Website: [samuelagenorwoth.com](https://samuelagenorwoth.com)

**Tools:** Python, PyTorch, FEniCS, MATLAB, Fortran, COMSOL

**Selected projects**

-  [Finite elements in 2D, built from scratch](https://github.com/samuelagenorwoth/finite-elements-2d): P1 finite elements in NumPy/SciPy on a square and an L-shaped domain, with an error study that shows the effect of the re-entrant corner.
- [Absorbing boundary conditions](https://github.com/samuelagenorwoth/absorbing-boundary-conditions): 2D wave equation in Python, comparing reflecting walls with Engquist–Majda absorbing boundaries
- [Homogenization in a perforated domain](https://github.com/samuelagenorwoth/homogenization-perforated-domain): diffusion in a material full of small holes, with effective coefficients from periodic cell problems and an O(ε) convergence study, in Python with gmsh.
- [2D Ising model](https://github.com/samuelagenorwoth/ising-model-2d): Monte Carlo simulation in MATLAB, validated against the exact solution of Onsager and Yang
